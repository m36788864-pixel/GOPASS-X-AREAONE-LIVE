# GOPASS — Combined V8

รวมการแก้ Hero image, gradient fade, white public theme, contact section และ Render Docker deployment

## Render

เลือก Runtime แบบ Docker ได้ เพราะมี `Dockerfile` ที่ root

หรือใช้ Node Runtime:
- Build: `npm install`
- Start: `npm start`

## สำคัญ

ไฟล์ต้องอยู่ root ของ repository โดยตรง และต้องมี:

`images/event-banner.png`

ทดสอบรูปหลัง deploy ได้ที่:

`https://YOUR-DOMAIN.onrender.com/images/event-banner.png`
