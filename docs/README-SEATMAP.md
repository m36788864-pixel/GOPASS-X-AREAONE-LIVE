# GOPASS — โหมดผังที่นั่ง (Seat Map)

ตอนสร้าง/แก้ไขคอนเสิร์ตที่ **Admin → คอนเสิร์ต** เลือก "รูปแบบการกดบัตร" ได้ 2 แบบ

| โหมด | ผู้ซื้อทำอะไร |
|------|---------------|
| บัตรยืน | เลือกประเภทบัตร + จำนวน (ระบบเดิม ไม่เปลี่ยน) |
| ผังที่นั่ง | เลือกที่นั่งจากผัง ที่นั่งที่ถูกซื้อ/ถูกจองจะกดไม่ได้ |

## ออกแบบผัง (โหมดผังที่นั่ง)
- กำหนดจำนวนแถว/คอลัมน์ หรือเลือกแม่แบบ (สี่เหลี่ยม, ทรง T แบบในภาพ, พัด, มีทางเดิน)
- คลิก/ลากเพื่อทาสีที่นั่งตามโซน · Shift ค้างหรือเครื่องมือ "ลบที่นั่ง" เพื่อเอาที่นั่งออก (ทำช่องว่าง/ทางเดิน/รูปทรงอะไรก็ได้)
- คลิกเลขคอลัมน์ด้านบน หรือปุ่มท้ายแถว เพื่อเติม/ล้างทั้งคอลัมน์/แถว
- หลายโซน (สูงสุด 12) แต่ละโซนตั้งชื่อ สี ราคาได้ · แก้ชื่อแถวได้ (A,B,C / 1,2,3 / พิมพ์เอง)
- ตั้งป้ายเวที ตำแหน่งเวที (บน/ล่าง) และด้านที่แสดงชื่อแถว

## กฎของระบบ
- ที่นั่งที่ลูกค้ากดเลือกจะถูกสำรอง 10 นาที (เท่ากับตัวนับเวลาหน้าเลือกที่นั่ง) ถ้าไม่กรอกข้อมูลทันเวลา ที่นั่งจะคืนให้คนอื่นอัตโนมัติ
- สองคนกดที่นั่งเดียวกันพร้อมกัน → ได้คนเดียว อีกคนจะได้ข้อความให้เลือกใหม่ (ล็อกฝั่งเซิร์ฟเวอร์)
- ราคาคิดจากฝั่งเซิร์ฟเวอร์ตามโซนของที่นั่งเสมอ
- งานที่เริ่มมีคำสั่งซื้อแล้ว: เปลี่ยนโหมด ยืน/ผัง ไม่ได้ และลบที่นั่งที่ถูกจอง/ขายแล้วออกจากผังไม่ได้ (แก้ราคา/ชื่อโซน/เพิ่มที่นั่งได้)

## ไฟล์ที่เพิ่ม/แก้
- เพิ่ม: `js/seatmap.js` (ตัวออกแบบผัง + หน้าเลือกที่นั่ง)
- แก้: `api/index.php`, `js/app.js`, `css/app.css`, `js/i18n.js`, `js/checkin.js`, `seat.html`, `buyer.html`, `receipt.html`, `admin/events.html`, `admin/report.html`

## API ที่เพิ่ม
- `GET /api/events/{id}/seats` → `{ sold: [...], held: [...] }`
- `POST /api/orders` รับ `{ eventId, seats: ["A1","B2"] }` เมื่องานเป็นโหมดผัง
