# GOPASS — รายชื่อและข้อมูลผู้ซื้อ

ปรับระบบยอดขายให้แสดงรายชื่อและข้อมูลผู้ซื้อรายออเดอร์ ได้แก่ ชื่อ-นามสกุล, เบอร์โทรศัพท์, อีเมล, Discord, Roblox, บัตร, จำนวน, ยอดรวม และสถานะเช็กอิน

## จุดที่ปรับ
- buyer.html เพิ่มฟอร์มชื่อและเบอร์โทรศัพท์
- server.js บันทึก buyer.name และ buyer.phone
- /api/admin/event-report/:eventId ส่งรายการ orders สำหรับหน้ารายงานยอดขาย
- admin/sales.html แสดงตารางรายชื่อผู้ซื้อและข้อมูลคำสั่งซื้อ และพิมพ์ PDF ได้
- admin/customers.html และ js/app.js แสดงชื่อ/โทรศัพท์เพิ่ม
- Google Apps Script รับชื่อ/โทรศัพท์เพิ่มในชีต Members

## หมายเหตุ
ออเดอร์เก่าที่สร้างก่อนเพิ่มสองช่องนี้จะไม่มีชื่อ/โทรศัพท์ จะแสดงเป็น "-" จนกว่าจะมีการสร้าง/แก้ไขข้อมูลผู้ซื้อใหม่
