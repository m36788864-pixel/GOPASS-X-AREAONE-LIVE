โหมดปรับปรุงระบบ

ข้อความหน้า Maintenance

กำหนดภาษาไทยและภาษาอังกฤษแยกกันได้ในแต่ละบรรทัด หากเว้นว่าง ระบบจะใช้ข้อความเริ่มต้นเดิม

กำหนดเวลา Maintenance & Countdown

ตั้งเวลาไทย (UTC+7) ให้ระบบเปิด Maintenance ตามกำหนด และเปิดเว็บกลับอัตโนมัติได้

หากเปิดตารางเวลา ระบบจะใช้กำหนดการนี้ควบคุมสถานะ Maintenance แทนสวิตช์เปิด/ปิดแบบปกติ ตรวจสอบวันเวลาให้ถูกต้องก่อนบันทึก

การเปลี่ยนสถานะจะมีผลกับผู้ชมทุกคนภายในไม่กี่วินาที

Security & Protection

ตรวจจับการเปิด DevTools ในเบราว์เซอร์และบังหน้าเว็บไซต์ด้วย Security Error Overlay เท่านั้น ระบบนี้ไม่สามารถป้องกันการเข้าถึงข้อมูลฝั่งเบราว์เซอร์ได้ 100%

การทำงาน

เมื่อเปิดใช้งาน ระบบจะตรวจจับปุ่มลัด DevTools และการเปลี่ยนขนาดหน้าต่างที่อาจเกิดจาก DevTools หากปิดเครื่องมือแล้ว Overlay จะหายไปเอง ไม่บังคับ Fullscreen ของเบราว์เซอร์

การตรวจจับเป็นแบบ best-effort และอาจเกิด false positive ได้ในบางหน้าต่าง/เบราว์เซอร์

ข้ามการป้องกันเฉพาะอุปกรณ์นี้

ใช้หลังจากผู้ดูแลเข้าสู่ระบบแล้ว เพื่อให้เครื่องนี้ไม่แสดง Overlay โดยไม่เปลี่ยนค่าของผู้ชมคนอื่น

กำลังตรวจสอบสถานะอุปกรณ์...
การตั้งค่านี้มีผลกับผู้ชมทุกคน ยกเว้นอุปกรณ์ที่ตั้งค่า bypass เฉพาะเครื่องไว้
